# SGIPC - Special Group Interested In Programming Contest

A modern, responsive website for KUET's competitive programming community.

## Overview

SGIPC is a dynamic web platform showcasing KUET's competitive programming achievements, learning resources, and community activities. The website features a sleek design with gradient backgrounds, smooth animations, and full mobile responsiveness.

## Features

### 🎯 Core Sections

- **Home & Achievements** - Showcases ICPC World Final 2024, Regional Dhaka 2025, and community milestones with high-quality images
- **About Us** - Details about SGIPC's mission and culture focused on algorithmic excellence and ICPC preparation
- **Stories, Highlights and Useful Links** - Featured moments and external contest resources (Codeforces, ICPC Global)
- **Recent Contest Performance** - Styled table showing team rankings and contest results
- **Practice Roadmap at a Glance** - Weekly Focus and Contest Routine lists
- **Join the SGIPC Community** - Registration form for new members
- **Contests & Rankings** - Live contest statistics and ranking system
- **Team Formation Contest Update** - Selection criteria, status, and timeline
- **Learning Roadmap** - Skill progression paths with progress indicators
- **Resources** - Learning materials for Beginner, Intermediate, and Advanced levels
- **Guidelines** - Best practices for members

### 🎨 Design Features

- **Modern Gradient Backgrounds** - Radial gradients with CSS variables for consistent theming
- **Responsive Grid Layout** - Adapts seamlessly from desktop to mobile
- **Smooth Animations** - Reveal effects and hover transitions
- **Styled Navigation Bar** - Sticky header with dropdown menu for easy navigation
- **Card-based Layout** - Clean, organized content presentation
- **Professional Typography** - Google Fonts (Manrope, Sora) integration

### 🛠️ Technical Highlights

#### HTML Structure

- Semantic HTML5 document with proper meta tags
- Organized sections with meaningful IDs and ARIA labels
- Image attributes: src, alt, width, height, title
- Form with multiple input types: text, password, radio, checkbox, select, textarea
- Tables with proper thead/tbody structure
- Ordered and Unordered lists with custom styling
- Block (div) and inline (span) elements used correctly

#### CSS Features

- **CSS Selectors:** Element, class, ID, universal, pseudo-classes
- **Box Model:** Margin, padding, border styling throughout
- **Link States:** :link, :visited, :hover, :active pseudo-classes
- **Layout Techniques:**
  - CSS Grid (responsive 2-column and 3-column layouts)
  - Flexbox for navigation and inline options
  - Float styling demo
  - Z-index layering for navbar and dropdown
- **Visual Effects:**
  - Box shadows and gradients
  - Opacity controls for transparency
  - Filter effects for image enhancement
  - Smooth transitions on hover
- **Responsive Design:** Media queries for tablets and mobile devices
- **Table Styling:** Styled borders, alternating row colors, hover effects
- **List Styling:** Custom bullet markers and numbered formatting

### 📱 Responsive Breakpoints

- **Desktop (> 860px)** - 3-column grid layouts
- **Tablet (860px - 700px)** - 2-column grid layouts
- **Mobile (< 700px)** - Single column, optimized touch targets

## Getting Started

1. Open `sgipc.html` in any modern web browser
2. Navigate through sections using the sticky header navigation
3. Use the dropdown menu under "Explore" for quick access to features
4. Fill the registration form to join SGIPC
